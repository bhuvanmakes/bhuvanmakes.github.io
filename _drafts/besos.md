This is a draft. It is not on the public blog until it is moved into `_posts`.

BESOS stands for Book Electronic Simple Open Source. The project is an e-ink reader designed to be simple, easy to use and open.

As of 24 November 2026 there is no Instructables, Hackster or YouTube write-up, and no public repository under github.com/bhuvanmakes. Earlier public notes described firmware for the reader; PCB and 3D-print files were promised in that description, but should not be treated as published until they actually appear in a public repository. This draft will not claim those files are available.

What belongs in a later, finished post:

- A photograph of the built reader, not a mock-up
- The hardware (panel, board, buttons, power)
- How to flash the firmware
- How reading progress is stored, and how the buttons work
- Honest status: what already works, and what is still unfinished
- Licence and a public github.com/bhuvanmakes repository, once it exists

Until those pieces are published, the live project page stays short.
